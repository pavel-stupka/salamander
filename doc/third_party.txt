=== Shiki (Code Viewer syntax highlighting) ===
The Code Viewer (codeview) plugin highlights source code with Shiki
(https://shiki.style), used as @shikijs/core plus the Oniguruma regular
expression engine (@shikijs/engine-oniguruma, which embeds the Oniguruma
library compiled to WebAssembly). Shiki is distributed under the MIT license
(see doc\license\license_mit.txt). The bundled engine is generated by
tools\codeview\build_web.py from the versions pinned in
tools\codeview\pins.json and ships inside codeview.spl.
Copyright (c) 2021 Pine Wu, Anthony Fu

=== TextMate grammars and VS Code themes (Code Viewer) ===
The Code Viewer ships 224 TextMate grammars from the tm-grammars collection
(https://github.com/shikijs/textmate-grammars-themes) and 12 colour schemes
(5 light, 7 dark) from the matching tm-themes collection. Each grammar and
theme keeps the license of the project it comes from; the complete, per-asset
list with the license and the upstream source of every shipped file is
generated into src\plugins\codeview\web\licence-manifest.json and is part of
the source distribution.

Most of these files are MIT-licensed. The following are under the Apache
License 2.0, which is compatible with this product's "GPL version 2 or later"
license only through the "or later" clause:
  actionscript-3, ara, ballerina, cadence, cairo, chapel, elixir, erlang,
  gleam, gn, jsonnet, kdl, lean, llvm, mojo, moonbit, ocaml, pkl, polar,
  prisma, puppet, smithy, surrealql, typst

18 grammars and one theme are deliberately NOT shipped because their license
is GPL-3.0-only or could not be established:
  ada, ahk2, apl, dax, dream-maker, glsl, gnuplot, hurl, kusto, matlab,
  nginx, org, racket, rel, sparql, tcl, ts-tags, turtle, theme aurora-x.
Where a shipped grammar imports an excluded one, an empty placeholder module
is shipped in its place so the importing grammar keeps working.
