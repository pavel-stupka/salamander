Opening Command Shell

You can open a command shell window for the current directory. Which program opens - Command Prompt (the default), Windows PowerShell, PowerShell 7, Windows Terminal, Git Bash or a program of your choice - is set on the Command Shell page of the Configuration dialog box.

To open the command shell window:

Menu:Commands/Command Shell
Shortcut key:Num / or Ctrl+/
Toolbar:Choose the Command Shell button on the Top or Middle toolbar.

Remarks

The program starts in the directory of the active panel. When the panel shows an archive, that is the folder containing the archive; when it shows a plugin file system (for example FTP or SFTP), no starting directory is set.

Whether the program accepts a network (UNC) path as its starting directory is the program's own behaviour: Command Prompt does not support UNC paths and falls back to the Windows directory, while PowerShell, Windows Terminal and Git Bash accept them. Windows itself refuses to start any program in a directory whose path has 259 or more characters; Tandem Commander then retries with the short (8.3) form of the directory.

On Windows 11 with Windows Terminal set as the default terminal application, console programs such as Command Prompt and PowerShell open inside Windows Terminal.
