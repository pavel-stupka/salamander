Tandem Commander: Dialog Boxes: Configuration

Command Shell

Chooses the program that the Command Shell command (Num /, Ctrl+/, the Commands menu, the toolbar button) opens. The program always starts in the directory of the active panel.

Dialog Box Options

Program
The program to open. The list offers Command Prompt (the default: the system command interpreter, as in earlier versions), Windows PowerShell, PowerShell 7, Windows Terminal, Git Bash and Custom program. A preset that is not installed on this computer is marked (not found) and cannot be confirmed; select another one or use Custom program. Presets are looked up at their standard installation places; an installation elsewhere is served by Custom program.
Found at
The full path of the program the selected preset will start, so you can tell which installation is used (for example PowerShell 7 versus Windows PowerShell).
Custom program: Program
The path of your own program. Use the ... button to browse for it. The path may contain $(WinDir), $(SysDir), $(SalDir) and $[NAME] for the value of the environment variable NAME. When you switch to Custom program while both fields are empty, they are filled with the program and arguments of the preset selected until then, so a preset is a starting point for your own settings (for example a specific Windows Terminal profile). Text you have entered is never overwritten.
Custom program: Arguments
Optional arguments. $(FullPath) is replaced by the directory of the active panel without a trailing backslash (for example D:\Work); a drive root keeps it (C:\). $(WinDir), $(SysDir), $(SalDir) and $[NAME] work as in the program field. Since the program starts in the panel directory anyway, arguments are only needed for programs that ignore their starting directory. Windows treats a backslash before a quotation mark as an escape, so "$(FullPath)" for a drive root reaches the program as C:"; use it without quotation marks or append a dot ("$(FullPath).") in that case.

Remarks

Changes apply to the next Command Shell command; no restart is needed. The setting is stored with the rest of the configuration and travels with an exported configuration. If the configured program cannot be started (it was uninstalled, or the path is wrong), the command shows an error naming the program and the reason; nothing else is started.

Whether a program accepts a network (UNC) path or a very long path as its starting directory is the program's own behaviour: Command Prompt falls back to the Windows directory for a UNC path, while PowerShell, Windows Terminal and Git Bash accept it. Windows itself refuses to start any program in a directory whose path has 259 or more characters; Tandem Commander then retries with the short (8.3) form of the directory.
